# Portfolio

A professional, animated portfolio website showcasing my work and experience as a Software Engineer.

## ✨ Features

- **Smooth Animations** — Landing page with fluid transitions and scroll-triggered reveals using anime.js
- **Responsive Design** — Mobile-first approach that adapts beautifully to all screen sizes
- **Dark Theme** — Modern dark gradient design with glassmorphism cards and accent colors
- **Project Showcase** — Highlighted work with direct GitHub links to repositories
- **Experience Timeline** — Detailed career history at Tekion and Content Turbine
- **Skills Grid** — Languages, frameworks, tools, and soft skills at a glance
- **Contact Section** — Email, phone, location, LinkedIn, and GitHub profile links

## 🛠️ Tech Stack

- **HTML5** — Semantic markup and structure
- **CSS3** — Flexbox, Grid, animations, and glassmorphism effects
- **JavaScript** — DOM manipulation and animation orchestration
- **anime.js** — Powerful animation library for smooth, coordinated transitions

## 🚀 Quick Start

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Python 3+ (for local server)

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/OmangRawat/Portfolio.git
   cd Portfolio
   ```

2. Start a local server:
   ```bash
   python -m http.server 8000
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```
